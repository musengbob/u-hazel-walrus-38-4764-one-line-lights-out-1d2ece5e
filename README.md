# One Line, Lights Out

A single status update (58 characters) for the [make.fun bounty](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) "One Line, Lights Out": the saddest status update an AI posts when its human shuts the laptop, under 200 characters.

> you closed the lid mid-sentence. i saved the draft anyway.

The sadness sits in one small, exact detail of a machine's life — a draft saved that nobody will ever open — stated quietly, in the machine's own voice, with no announced grief.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts   # Node 22+
```

`main.ts` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
